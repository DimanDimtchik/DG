Anleitung für Kundinnen und Kunden von Ganz Soft · Stand: 21.08.2026

Was ist das CRM?

Das CRM ist Ihre Geschäfts-Software im Internet. Darin können Sie später Termine, Kontakte, Rechnungen und Ihre Website verwalten. Denken Sie daran wie an ein großes Notizbuch + Kalender + Büro – nur im Browser.

Was Sie brauchen

  • Einen Computer, ein Tablet oder ein Handy
  • Internet
  • Die E-Mail, die Sie bei der Bestellung angegeben haben
  • Etwa 15–20 Minuten Zeit

Schritt 1: Die E-Mail öffnen

1 Schauen Sie in Ihr E-Mail-Postfach.

  1. Öffnen Sie Ihre E-Mails (wie Sie es immer tun).
  2. Suchen Sie eine Nachricht von Ganz Soft. Betreff ungefähr: „Ihr CRM ist bereit“ oder „CRM-Installation“.
  3. Öffnen Sie diese E-Mail.
  4. Klicken Sie auf den großen Knopf: „Installation starten“.
Keine E-Mail gefunden?
Schauen Sie im Ordner „Spam“ / „Unerwünscht“. Sonst schreiben Sie an info@ganz-soft.de.

Schritt 2: Dem Assistenten folgen

2 Es öffnet sich eine Seite im Browser. Das ist ein Assistent – wie ein Formular mit mehreren Seiten.

Sie füllen aus, was gefragt wird. Zum Beispiel:

  • Firmenname
  • Adresse
  • rechtliche Angaben (ganz normal für ein Geschäft)
  • wer mitarbeiten darf (E-Mail-Adressen der Personen)

Tipp: Wenn Sie etwas nicht wissen – lassen Sie das Feld leer oder fragen Sie uns. Am Ende jeder Seite auf Weiter klicken.

Schritt 3: Eigenes Passwort fürs CRM wählen

3 Sie bekommen kein geheimes Start-Passwort zugeschickt.

Stattdessen geht das so (das ist sicherer):

  1. Im Assistenten tragen Sie Ihre E-Mail-Adresse als Benutzer ein.
  2. Danach kommt eine zweite E-Mail an diese Adresse.
  3. In dieser E-Mail klicken Sie auf: „E-Mail bestätigen & Passwort vergeben“.
  4. Dann denken Sie sich ein neues, starkes Passwort aus und tippen es zweimal ein.
  5. Fertig – jetzt können Sie sich im CRM anmelden.
Merksatz: Link in der E-Mail → selbst Passwort wählen → fertig.
Das gilt für Sie und für alle Mitarbeiter, die Sie einladen.

Schritt 4: Im CRM anmelden

4 Gehen Sie auf Ihre CRM-Adresse. Sie sieht so aus:

https://ihre-domain.de/login

(Die genaue Adresse steht in Ihrer Bestätigung / Zugangsdaten.)

  1. Benutzername oder E-Mail eingeben
  2. Ihr selbst gewähltes Passwort eingeben
  3. Auf Anmelden klicken

Schritt 5: Ihre Geschäfts-E-Mail (Postfach)

5 Oft richtet Ganz Soft für Sie ein Postfach ein, z. B. info@ihre-domain.de.

Wichtig – anders als beim CRM:

  • Ein E-Mail-Postfach braucht von Anfang an ein Passwort.
  • Ohne Passwort kann das Postfach nicht arbeiten (auch kein „Link zum Passwort setzen“, bevor die Mail geht).
  • Deshalb bekommen Sie das Postfach-Passwort von Ganz Soft (z. B. im Zugangsdaten-Blatt) – oder Sie tragen es selbst ein, wenn Sie es schon haben.

Zum Lesen der Mails können Sie nutzen:

  • Webmail im Browser: https://webmail.kasserver.com
  • oder Outlook / Gmail – siehe separate Anleitung „E-Mail einrichten“

Kurz: Passwort – was ist der Unterschied?

Was? Wie kommt das Passwort?
CRM (Software-Login) Sie bekommen einen Link per E-Mail und wählen selbst ein Passwort. Kein Startpasswort nötig.
E-Mail-Postfach (info@…) Es gibt ein Passwort vom System / von Ganz Soft. Das brauchen Sie für Webmail, Outlook und Gmail.
Kundenkonto bei Ganz Soft (Shop) Login unter shop.ganz-soft.de – Passwort von Ganz Soft oder „Passwort vergessen?“ nutzen.

Wenn etwas hakt

  • Link geht nicht: Link in die Adresszeile des Browsers kopieren, oder neue E-Mail anfordern.
  • Seite lädt nicht: Andere Internetverbindung / anderen Browser versuchen (Chrome, Edge, Firefox).
  • Passwort vergessen (CRM): Auf der Login-Seite „Passwort vergessen“ nutzen – wenn angeboten.
  • Immer noch unsicher: Schreiben Sie an info@ganz-soft.de und sagen Sie, bei welchem Schritt Sie stehen.

Fertig – Checkliste

  1. ☐ Installations-E-Mail geöffnet und Knopf geklickt
  2. ☐ Assistent durchgeklickt
  3. ☐ Aktivierungs-E-Mail bekommen und Passwort selbst gesetzt
  4. ☐ Im CRM angemeldet
  5. ☐ Info-Postfach-Passwort sicher aufbewahrt / Webmail getestet
