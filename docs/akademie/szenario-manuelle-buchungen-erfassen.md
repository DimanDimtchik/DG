# Szenario: Manuelle Buchungen — Erfassen

> **Regeln:** [`VIDEO-REGELN.md`](VIDEO-REGELN.md) · **Text:** [`locales/de/manuelle-buchungen-erfassen.json`](locales/de/manuelle-buchungen-erfassen.json)

**Zielgruppe:** Buchhaltung / Admin mit Schreibrecht  
**Dauer:** ca. 2 Minuten  
**Stil:** Dashboard → Formular „Neue Buchung“ → Felder → Speichern

## Botschaft

So erfassen Sie eine ausgeglichene Buchung: Datum, Beschreibung, Zeilen mit Konto, Gegenkonto, Soll/Haben, Betrag und optionalem BU-Schlüssel.

## Ablauf

1. Dashboard → Kachel  
2. Formular „Neue Buchung“  
3. Datum und Beschreibung  
4. Buchungszeilen (Konto, Gegenkonto, S/H, Betrag, BU, Text)  
5. Speichern und Hinweis Soll = Haben  
6. Abschluss
