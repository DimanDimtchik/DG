# Szenario: Manuelle Buchungen — Überblick

> **Regeln:** [`VIDEO-REGELN.md`](VIDEO-REGELN.md) · **Text:** [`locales/de/manuelle-buchungen-ueberblick.json`](locales/de/manuelle-buchungen-ueberblick.json)

**Zielgruppe:** Buchhaltung / Admin mit Schreibrecht  
**Dauer:** ca. 1,5–2 Minuten  
**Stil:** Dashboard → Kachel → Seite (Jahr, Liste, Zweck)

## Botschaft

Manuelle Buchungen sind freie Journalbuchungen **ohne Beleg**. Sie ergänzen Belege und Bank — z. B. Umbuchungen oder Korrekturen. Soll und Haben müssen ausgeglichen sein.

## Ablauf

1. Dashboard → Kachel Manuelle Buchungen  
2. Seite: Zweck kurz erklären  
3. Geschäftsjahr wählen  
4. Liste der Buchungen im Jahr  
5. Abschluss → Verweis auf Erfassen-Video
