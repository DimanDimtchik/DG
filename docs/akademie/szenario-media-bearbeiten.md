# Szenario: Media — Bearbeiten

> **Regeln:** [`VIDEO-REGELN.md`](VIDEO-REGELN.md) · **Text:** [`locales/de/media-bearbeiten.json`](locales/de/media-bearbeiten.json)

**Zielgruppe:** Administratoren  
**Dauer:** ca. 3–4 Minuten  
**Stil:** Bild öffnen — linke Spalte (Vorschau/Logo) und rechte Spalte (Metadaten bis Löschen)

## Ablauf

1. Dashboard → Media → Liste → Bearbeiten  
2. Links: Vorschau, Technik, Logo/Favicon  
3. Rechts: Metadaten (Titel, Alt, Quelle) speichern  
4. Größe & Format → neues Bild  
5. Zuschneiden  
6. Hintergrund entfernen / Freistellen  
7. Löschen  
8. Verwendung scannen  
9. Abschluss
