# Szenario: Akademie — Kurs lernen

> **Regeln:** [`VIDEO-REGELN.md`](VIDEO-REGELN.md) · **Text:** [`locales/de/akademie-kurs-lernen.json`](locales/de/akademie-kurs-lernen.json)

**Zielgruppe:** Anwender, die einen Kurs absolvieren  
**Dauer:** ca. 2–3 Minuten  
**Stil:** Vom Dashboard in einen Kurs; Regeln → Module → Videoplayer

## Ablauf

1. Dashboard → Akademie → Katalog / Kurs öffnen  
2. Schulungsregeln bestätigen  
3. Modulliste mit Fortschritt  
4. Modul / Videoplayer (Untertitel, Tempo max. 2×)  
5. Modul abschließen und zurück zum Kurs
