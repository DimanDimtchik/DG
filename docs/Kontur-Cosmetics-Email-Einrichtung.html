1. Outlook (Windows – Microsoft Outlook)

Neues Konto hinzufügen

  1. Outlook öffnen → Datei → Konto hinzufügen (oder: Datei → Kontoeinstellungen → E-Mail-Konten → Neu).
  2. E-Mail-Adresse eingeben: info@kontur-cosmetics.de → Weiter.
  3. Wenn Outlook das Konto nicht automatisch findet: Manuelle Einrichtung / Erweiterte Optionen wählen → Ich möchte mein Konto manuell einrichten.
  4. Kontotyp: IMAP wählen.
  5. Serverdaten wie in der Tabelle oben eintragen (IMAP 993 SSL, SMTP 465 SSL).
  6. Benutzername: info@kontur-cosmetics.de, Passwort eingeben.
  7. Unter SMTP: Option Authentifizierung erforderlich / dieselben Anmeldedaten wie für den Posteingang aktivieren.
  8. Verbindung testen und mit Fertig stellen bestätigen.

Falls schon ein Konto existiert und angepasst werden soll

  1. Datei → Kontoeinstellungen → Kontoeinstellungen…
  2. Konto markieren → Ändern → Weitere Einstellungen.
  3. Reiter Server: SMTP-Anmeldung aktivieren.
  4. Reiter Erweitert: Ports 993 (IMAP/SSL) und 465 (SMTP/SSL) prüfen.

4. Gmail im Browser (Mails über Gmail abrufen)

Damit erscheinen die Mails von info@ in Ihrem Gmail-Posteingang. Senden über info@ ist optional.

Posteingang abrufen (IMAP)

  1. In Gmail (Browser): Zahnrad → Alle Einstellungen anzeigen.
  2. Reiter Konten und Import → unter „E-Mails aus anderen Konten abrufen“: E-Mail-Konto hinzufügen.
  3. Adresse info@kontur-cosmetics.de eingeben → Weiter → E-Mails über mein anderes Konto abrufen (POP3) erscheint manchmal zuerst; wenn möglich IMAP nutzen. Falls nur POP3 angeboten wird:
    • POP-Server: w0217246.kasserver.com, Port 995, SSL aktiv
    • Benutzername: volle E-Mail-Adresse
    Hinweis: POP lädt Mails oft nur in den Posteingang und lässt sie am Server optional stehen – IMAP (App/Outlook) ist für den Alltag besser.

Mit info@ über Gmail senden (SMTP)

  1. Einstellungen → Konten und Import → „Nachricht senden als“ → Weitere E-Mail-Adresse hinzufügen.
  2. Name und Adresse info@kontur-cosmetics.de eintragen.
  3. SMTP-Server: w0217246.kasserver.com, Port 465, Benutzername volle Adresse, Passwort, SSL.
  4. Bestätigungscode aus dem Postfach eingeben (kommt an info@).
